# FitBuddy: AI-Powered Fitness Plan Generator

This repository implements FitBuddy as a runnable FastAPI web application.

**Live link:** https://fitbuddy-u8r0.onrender.com/

## What is included

- FastAPI backend
- Jinja2/HTML/CSS frontend
- User profile form with Pydantic validation
- 7-day workout plan generated by Google Gemini through the google-genai SDK
- Nutrition tip with a built-in fallback tip
- Feedback step that returns a complete updated plan
- Gemini model fallback chain
- SQLite storage for users and plans
- Coach view with delete option
- Swagger/OpenAPI documentation at `/docs`

## Current Gemini model

The workout model defaults to `gemini-3.6-flash` and the tip model to `gemini-3.5-flash-lite`. Change `WORKOUT_MODEL` and `TIP_MODEL` in `.env` if your account provides other supported models.

## VS Code

1. Install Python 3.10+.
2. Open this folder in VS Code.
3. Open Terminal.
4. Create/activate a virtual environment.
5. Install requirements.
6. Create a `.env` file and add `GOOGLE_API_KEY=your_api_key_here`.
7. Run `uvicorn app.main:app --reload`.
8. Open http://127.0.0.1:8000.

### Windows

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### macOS/Linux

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Then visit `/docs` for API testing.

## Typical test flow

1. Open the home page and submit: Anu, user ID 1, age 18, weight 50, goal Weight loss, intensity High.
2. Check the 7-day plan and nutrition tip.
3. Submit feedback: "Add more rest days please".
4. Verify the updated plan and open "View your original plan".
5. Open Coach view (`/view-all-users`) and verify history.
6. Delete the user and verify it is removed.

If the Gemini API key is missing or invalid, the app shows a clear error message.

## Architecture

Browser → FastAPI routes → Pydantic validation → Gemini (with fallback models) → SQLite → browser.

## Production notes

- Keep `.env`, `venv/` and `fitbuddy.db` out of Git.
- Do not expose `GOOGLE_API_KEY` to the frontend.
- Add login before storing real user data.
- Use a production database such as PostgreSQL.
- Add rate limiting, structured logging and HTTPS.
- FitBuddy gives general fitness suggestions and is not medical advice.
